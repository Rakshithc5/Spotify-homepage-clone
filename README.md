# Spotify Homepage UI Clone

A homepage recreation inspired by Spotify, built with **HTML and CSS** to practise front-end layout and styling.

## Highlights
- Music-streaming-inspired page layout
- CSS styling, spacing, and typography
- Responsive design practice

## Built With
- HTML
- CSS

## Run Locally
Open the main HTML file in a modern web browser.

This is an independent educational UI project and is not affiliated with Spotify.
